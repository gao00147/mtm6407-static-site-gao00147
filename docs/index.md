## Hi, I'm Yijia

I studied visual communication at Luxun Academy of Fine Arts, then spent a few years doing web and visual design. In 2025 I came to Ottawa to study Interactive Media Design, because I wanted to build the things I was designing instead of handing them off.

Fall 2026 is my final term. After I graduate I'm looking for a hybrid designer and developer role, where I can do UI design and front-end work on the same team.
